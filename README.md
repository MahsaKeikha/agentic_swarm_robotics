# F79 Agentic Swarm Robotics

Standalone multi-agent reference implementation for swarm robotics architecture, coordination strategy review, simulation, communication resilience, safety analysis, and evaluation.

Agents: [Swarm Architecture](AGENTS/swarm_architecture_agent.py), [Coordination Strategy](AGENTS/coordination_strategy_agent.py), [Simulation](AGENTS/simulation_agent.py), [Communication Resilience](AGENTS/communication_resilience_agent.py), [Safety](AGENTS/safety_agent.py), [Evaluation](AGENTS/evaluation_agent.py).

Tools are in `TOOLS/`, skills in `SKILLS/`, with orchestration, memory, state, schemas, prompts, config, safety, observability, evals, benchmarks, examples, tests, docs, and CI.

This repository is simulation oriented and does not control physical robot swarms.
